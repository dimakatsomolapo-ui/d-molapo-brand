IMPORTANT FOR GMAIL
For recipients to see the images and use SAVE CONTACT, upload this package to GitHub Pages.
Then open gmail-signature-HOSTED-TEMPLATE.html and replace every:
YOUR_GITHUB_PAGES_URL
with your live repository Pages URL, for example:
https://dimakatsomolapo-ui.github.io/dimakatso-molapo-personal-brand

Save it, open the hosted HTML in Chrome, copy the rendered signature, and paste it into Gmail Settings > General > Signature.

The phone, email, LinkedIn, portfolio and Save Contact are separate clickable HTML links.
